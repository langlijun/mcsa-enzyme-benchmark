# Data and licensing status

This is a private development repository until the maintainer approves a public
release. A code license has not yet been selected. Do not describe it as an
open-source release or infer permission to redistribute third-party materials.

Included: evaluator source, reviewed case definitions and evidence references,
configuration hashes, test code, synthetic examples and usage documentation.

Not included: predicted or experimental coordinate files, model weights, MSA or
template databases, article PDFs, private rank/evaluation tables, spreadsheets,
server scripts, credentials, personal paths, or full development archives.

Some case definitions contain small reference-derived geometry/anchor data
necessary to implement reviewed assignments. A public release must review the
provenance and applicable permissions of these data as well as the predicted
coordinate archive. Linked articles remain under their own licenses.

Future data releases should use a versioned external archive with checksums,
input contracts, native-rank provenance, attribution and a clear license. A
code-only repository cannot claim that the entire 400-structure experiment is
publicly reproducible before the required data are released.
